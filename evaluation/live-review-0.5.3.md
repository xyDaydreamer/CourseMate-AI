## 缺陷的独立核对

1. **代码边界**：真实选区最后一条语句为 `System.out.println(countWords("Java maps Java collections"));`，两个调用括号和分号都存在，只省略外围方法 / 类的闭合大括号。给 `countWords` 添加测试桩并仅补外围大括号后，用 JDK 25 `javac` 编译通过；测试文件和编译产物保存在 `.coursemate/acceptance/SnippetBoundaryCheck.java` 和 `snippet-classes/`。这只核对可见语句的结构，不声称原用户项目已编译。
2. **原子性**：本机 JDK 25 `lib/src.zip` 中 `java.base/java/util/HashMap.java` 的类文档明确写明实现未同步。课程 Map 第 15 页只展示计数语法和几种 Map 的顺序特征，没有给出原子性保证。
3. **null 行为**：执行 `.coursemate/acceptance/LiveClaimChecks.java`，先 `put("java", null)`，再以非 null 的 `1` 和 `Integer::sum` 调用 `merge`，实际返回 `1`、没有 NPE。同一检查确认样例字符串为 4 个空白分隔词。
